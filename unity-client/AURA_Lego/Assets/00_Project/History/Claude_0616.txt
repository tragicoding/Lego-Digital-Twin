주제: 광장 좋아요 패널(LikePanel)을 오브제 '앞'(플레이어 눈높이)에 배치.
      말풍선(BubblePanel) 배치 로직과 공통화하여 중복 제거.
      공통 원칙: 저결합·중복 제거·확장성·Mock/Server 동일 동작.


────────────────────────────────────────────────────────────────
[세션 1] LikePanel 오브제 앞 배치
────────────────────────────────────────────────────────────────

## 배경
  LikeSystem.likePanel(근접 시 뜨는 좋아요 버튼 UI)이 세션 뷰(스폰 포인트 고정)의
  자식이라, 오브제가 objectBackOffset 만큼 뒤로 가면 패널이 오브제와 멀어져 보임.

## 요구 변화 (사용자 요청 순서)
  1) 오브제에 붙게 → 처음엔 '위'에 배치
  2) '위'가 아니라 '앞'(플레이어/카메라 쪽)에 배치
  3) 오브제 크기에 따라 앞 거리 자동 조정
  4) 큰 오브제가 너무 멀다 → 더 가까이
  5) 높이를 플레이어 눈높이로

## 구현 (NameTag 확장 — 말풍선/이름표와 공유)
  NameTag.Bind 에 옵션 추가(기본값이라 이름표·말풍선엔 영향 없음):
    - forwardOffset       : 카메라 쪽(앞)으로 당기는 고정 여유(m)
    - forwardSizeFactor   : 오브제 반(半)깊이(카메라 방향) × 배율 → 크기 자동 조정
                            HalfDepthAlongCamera = |extents·cameraForward| (AABB 투영)
    - eyeLevel            : 높이를 플레이어(카메라) Y에 맞춤(오브제 높이 무시)
  전진 거리 = forwardOffset + halfDepth × forwardSizeFactor
  높이 기준 = eyeLevel ? 카메라Y : 바운즈 상단(머리 위)

## 공통화 (중복 제거)
  PlazaSessionView.ReparentPanelToObject(...) 로 패널 재배치 로직 단일화.
    - 말풍선/좋아요 패널이 같은 헬퍼 사용(독립 World Space 캔버스 + 카메라 빌보드).
    - 패널 stretch 앵커가 재부모 시 깨지지 않게 원래 크기·월드 스케일 캡처 후 복원.
    - 비활성 패널(LikePanel 은 접근 전 비활성)도 정확히 측정하도록 잠시 활성화 후 복원.
  PlaceBubbleAtObject : 말풍선(상단, 텍스트 크기 독립 조정)
  PlaceLikePanelAtObject : 좋아요 패널(앞 + 눈높이, 크기 비례 전진)

## 클릭 동작 보장 / 서버 동일
  - LikeSystem 은 RectTransformUtility 로 카메라 기반 직접 클릭 감지(GraphicRaycaster
    불필요) → 패널 재배치 후에도 좋아요 정상.
  - Mock·Server 모두 _lastSpawnedObjectGO 채우는 동일 합류점에서 호출 → 동일 동작.
  - 자기 창작물은 likePanel=null 이라 PlaceLikePanelAtObject 자연 no-op(투표 불가 유지).


────────────────────────────────────────────────────────────────
[세션 2] 코드 정리 — 미사용 옵션 제거
────────────────────────────────────────────────────────────────

  인스펙터 확정값(Forward Max=0 미사용)에 맞춰 죽은 코드 제거:
    - forwardMax(전진 거리 상한, cap) : 전 경로 삭제(NameTag/View/Manager 필드).
    - anchorAtCenter(바운즈 중앙 높이) : eyeLevel 에 항상 가려져 죽은 코드 → 삭제.
      높이 기준을 '눈높이 / 상단' 두 가지로 단순화.


────────────────────────────────────────────────────────────────
조정 파라미터 (PlazaManager 인스펙터)
────────────────────────────────────────────────────────────────
  likeObjectForwardOffset     = 3     (앞으로 당기는 고정 여유 m)
  likeObjectForwardSizeFactor = 0.65  (오브제 크기 비례 전진, 낮출수록 큰 오브제 가까이)
  likeObjectHeightOffset      = 0     (눈높이 기준 오프셋, +면 위)
  likeObjectScale / likeObjectRightOffset (크기 / 좌우)
