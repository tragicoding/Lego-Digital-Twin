### 2. SessionManager DontDestroyOnLoad 오류 수정

**수정:** `DontDestroyOnLoad(gameObject)` 호출 전에 `transform.SetParent(null)` 추가

### 3. CharacterAnimationController — Bool/Trigger 자동 감지

**배경:** Animator Controller에 Bool(`isWalking`) 방식과 Trigger(`walk`/`idle`) 방식이 혼재.
캐릭터가 실제로 움직이지 않는 문제 발생.

**수정 내용 (`CharacterAnimationController.cs`):**
- `walkBoolParam = "isWalking"`, `walkTrigger = "walk"`, `idleTrigger = "idle"` 필드 추가
- `Awake()`에서 `DetectAnimatorMode()` 호출 → Animator 파라미터를 스캔해 Bool/Trigger 자동 감지
- `animation_walk()` / `animation_idle()`: 감지된 방식에 따라 자동 분기
- Animator Controller 미연결 시 명확한 경고 메시지 출력 (물리 이동은 정상 동작)
- `AnimatorOverrideController` 초기화 — `PlayMotionClip(clip)`에서 "Motion" 슬롯 교체

**Animator Controller 위치:** `Assets/00_Project/Animations/Character/NPC_AnimatorController.controller`
**상태머신 구성:** Idle → Walk (Bool: `isWalking`) + Any State → Motion (Trigger: `motion`)

### 4. GuideNPCController — 등장 연출 및 이동 구현

**배경:** 캐릭터가 로그만 출력하고 실제로 움직이지 않았음.
NPC가 씬에 없고 런타임에 스폰되므로 Inspector 연결 불가.

**구현 내용:**
- `guideArrivalPoint` Transform 필드 추가 (등장 후 걸어가서 멈출 위치)
- `GuideScenarioRoutine()` Step 0: `guideArrivalPoint`까지 이동 후 플레이어 방향 회전
- `FacePlayerRoutine(duration)`: `Camera.main` 위치 기준으로 Y축 Slerp 회전
- `MoveRoutine(target)`: `Vector3.MoveTowards` + `Quaternion.Slerp` 이동
- Step 3(광장 이동): 대사와 동시에 이동 시작
- Step 4(창작물): `myCreationWaypoint`에 도착 후 `FacePlayerRoutine()` 호출
- `moveSpeed` 기본값: `2f` → 최종 `5f`로 변경

**웨이포인트 구조:**
- `guideSpawnPoint`: NPC 스폰 위치
- `guideArrivalPoint`: 등장 후 걸어가서 인사하는 위치
- `plazaPathWaypoints[]`: 광장까지 이동 경로
- `myCreationWaypoint`: 창작물 앞 위치
→ 모두 `GeneratedCharacterSpawner` Inspector에서 설정 후 NPC에 자동 주입

### 6. GeneratedObjectSpawner — 서버 GLB 오브제 스폰

**배경:** 오브제도 캐릭터처럼 서버에서 자동 연결·스폰 필요. 플레이 시작 시 스폰.

**구현 (`GeneratedObjectSpawner.cs` 전면 수정):**
- `Spawn(ObjectAssetData data)`: model_url 유무로 Mock/Server 분기

  ```
  로드 실패 시 SpawnMock() fallback
  ```
- `spawnScale` 필드로 스폰 크기 조절
- `GameFlowManager`에서 플레이 시작 시 자동 호출

### 7. PlayerFollowGuide — 가이드 모드 플레이어 거리 유지

**배경:** 가이드 모드에서 플레이어가 NPC를 따라가야 함.
광장 이동 시작 전(인사/소개 구간)에는 따라가면 안 됨.

**구현 변경 이력:**

**1차 — 고정 오프셋 방식 (취소)**
- NPC 뒤쪽 `followDistance` 위치로 Lerp 이동
- 사용자 요청으로 즉시 취소

**2차 — NPC 이동 방향 기반 (회전 무관)**
- 요구사항: NPC 몸 회전에 플레이어 위치가 흔들리면 안 됨
- `transform.forward` 대신 프레임 간 위치 delta로 이동 방향 계산
- NPC 정지 회전 시 `_smoothMoveDir` 유지 → 플레이어 고정
- `followDistance = 10f`
- 문제: 플레이어가 NPC보다 앞서 나가는 현상 발생

**3차 — 최대 거리 유지(leash) 방식 (현재 적용)**
- NPC ↔ 플레이어 거리 ≤ `maxDistance`: 아무것도 안 함
- 초과 시: NPC 방향으로 Lerp 당김
- 방향/회전에 완전 무관
- `maxDistance = 5f` → `8f`, `smoothSpeed = 3f` → `5f`

**최소 거리 추가 시도 (롤백)**
- `minDistance = 2f` 추가 (너무 가까우면 밀어냄)
- 작동 불량으로 진단용 Debug.Log 버전 시도
- 사용자 요청으로 롤백 (`maxDistance = 8f`, `smoothSpeed = 5f` 상태 유지)

**활성화 타이밍:**
- `GuideNPCController`에 `OnPlazaMoveStarted` 이벤트 추가
  - Step 3(광장 이동) 직전에 `Invoke()`
- `GameFlowManager`에서 구독 → `_playerFollowGuide?.StartFollowing(npc)` 호출
- `OnGuideFinished` 발생 시 `StopFollowing()` 자동 호출

```
Step 1-2  인사 + 월드 소개       → 플레이어 고정 (따라가기 비활성)
Step 3    광장 이동 시작          → OnPlazaMoveStarted → StartFollowing 활성화
Step 3~4  광장 이동 + 창작물 앞  → NPC 8m 초과 시 플레이어 자동 당김
Step 8    가이드 종료             → OnGuideFinished → StopFollowing 자동 해제
```
