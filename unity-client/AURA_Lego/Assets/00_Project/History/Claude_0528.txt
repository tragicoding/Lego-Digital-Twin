[세션 5] 서버 캐릭터 자동화 (컴포넌트 자동 주입)

## 배경
  서버에서 오는 FBX는 raw 오브젝트 → 수동 컴포넌트 추가 불가
  → GetOrAdd<T>() 패턴으로 자동 주입

## 수정 파일
  Scripts/Character/GeneratedCharacterSpawner.cs  (전면 수정)
  Scripts/Managers/GameFlowManager.cs             (SpawnPlaced 반환 타입 대응)

## 핵심 변경 내용

  추가된 메서드:
    SetupAsGuide(GameObject go, SessionData session)
      - GetOrAdd<CharacterAnimationController>
      - GetOrAdd<GuideNPCController>
      - npc.Animation 자동 연결 (null 일 때만)
      - npc.Initialize(session)

    SetupAsPlaced(GameObject go, SessionData session)
      - GetOrAdd<CharacterAnimationController>
      - GetOrAdd<PlacedCharacterController>
      - placed.motionLibrary 자동 연결 (null 일 때만)
      - anim.Initialize(character, bubble_text)

    GetOrAdd<T>(GameObject go)  [static 유틸]
      - GetComponent → 있으면 반환
      - 없으면 AddComponent → 반환

  SpawnGuide()  → CreateCharacterObject() + SetupAsGuide()
  SpawnPlaced() → CreateCharacterObject() + SetupAsPlaced()
                  반환 타입 GameObject → PlacedCharacterController 로 변경

  Inspector 추가 필드:

    spawnScale = 6f

    [Header("컴포넌트 자동 주입")]
    motionLibrary (MixamoMotionLibrary ScriptableObject)

────────────────────────────────────────────────────────────────

## 생성 파일
  Scripts/UI/DialogueUI.cs  (신규)

## 수정 파일
  Scripts/Managers/GameFlowManager.cs
    - using LegoTwin.UI 추가
    - [SerializeField] private DialogueUI _dialogueUI 필드 추가
    - private string _currentNpcName 필드 추가
    - OnSessionLoaded: _currentNpcName = session.character_npc_name
    - OnDialogueChanged: _dialogueUI?.Show(_currentNpcName, text)
    - OnGuideFinished: _dialogueUI?.Hide()

## DialogueUI 주요 기능
  - Show(string speakerName, string text)
      BubbleRoot 활성화
      SpeakerNameText = speakerName (NPC 이름)
      DialogueText    = text (대사)
      CanvasGroup 페이드 인 (0 → 1)

  - Hide()
      CanvasGroup 페이드 아웃 (1 → 0)
      BubbleRoot 비활성화

  - Billboard 모드 (billboardMode = true)
      LateUpdate에서 transform.forward = Camera.main.forward
      World Space Canvas 에서 항상 카메라 방향

## Inspector 필드
  _bubbleRoot       (GameObject)
  _speakerNameText  (TMP_Text)
  _dialogueText     (TMP_Text)
  _canvasGroup      (CanvasGroup)
  _fadeDuration     (float, 기본 0.25)
  _billboardMode    (bool, 기본 false)

## Unity Hierarchy 구조
  DialogueUI (Canvas)
    └── BubbleRoot (GameObject + CanvasGroup)
         └── BubblePanel (Image)
              ├── SpeakerNameText (TMP_Text)
              └── DialogueText    (TMP_Text)
