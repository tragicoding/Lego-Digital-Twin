[세션 1] FreeCameraController — 비VR 디버그 카메라 전면 개편
────────────────────────────────────────────────────────────────

## 배경
  에디터/관전용 자유 카메라(FreeCameraController)가 XR Origin (XR Rig)
  프리팹의 Main Camera에 부착되어 있어 VR 리그와 충돌. 이동/점프/단차
  처리 과정에서 다수 문제 발생 → 단계적으로 재구현.

## 변경 이력 (순서대로)

  1) Q/E 수직 이동 제거 → WASD 수평 전후좌우 이동만 유지
     - transform.forward/right를 Vector3.ProjectOnPlane로 평탄화
       (시선이 위/아래로 기울어도 수평 이동)
     - 대각선 속도 정규화(dir.normalized)

  2) 점프(Space) 추가
     - 초기엔 자체 중력 + "시작 높이 복귀" 방식 → 지형 높낮이에서 파고듦

  3) 지형 추적(레이캐스트) 시도 → 단차/오버슈트 문제로 폐기

  4) ★ CharacterController 기반으로 전면 재작성 (최종)
     - XR Origin 루트의 기존 CharacterController.Move() 구동
       → 벽 충돌·계단 오르기(stepOffset)·경사(slopeLimit)·중력·점프
         전부 엔진 기본 기능으로 처리
     - GetComponentInParent<CharacterController>()로 자동 배선
       (프리팹 직접 수정 없음)
     - 회전 분리: Yaw=리그 전체, Pitch=카메라 (우클릭 드래그)
     - 이동은 우클릭과 분리(항상 가능), 점프 중에도 전진 가능

  5) 충돌 XR 컴포넌트 자동 비활성화
     - 컴포넌트 활성 시 TrackedPoseDriver / ContinuousMoveProvider /
       GravityProvider / CharacterControllerDriver 등을 타입 이름으로
       찾아 비활성화 (비VR 디버그 전용, VR 빌드에선 이 스크립트만 끄면 원복)

  6) CC-safe 텔레포트 (GameFlowManager.OnPlayerTeleportRequested)
     - 활성 CharacterController에 transform.position 직접 대입 시
       내부 위치가 어긋나 이후 Move()가 묶이는 문제
     → CC 끄고 → position 설정 → 다시 켜기 패턴으로 수정

  7) ★ 한글(IME) 모드 키보드 입력 대응 (최종 핵심)
     - 증상: 한글 입력 모드에서 W·A·S·D(문자 키)가 안 들어옴.
             Space(비문자)는 됨. → IME가 문자 키를 조합용으로 가로챔.
     - 해결: 키보드를 새 Input System(Keyboard.current)으로 읽도록 변경.
             물리 키 단위라 IME와 무관하게 동작.
     - HeldKey()/PressedKey() 헬퍼 추가 (새 Input System 우선, 구 Input 폴백)
     - 마우스 회전은 구 Input 유지(IME 영향 없음), 모션 입력창 한글 타이핑 무관
     - asmdef 없음 → 기본 Assembly-CSharp이 Input System 자동 참조(컴파일 OK)

## 진단 메모 (이동 안 됨 → 원인 추적 순서)
  guide=False(게이트 OK) / cc=True(CC 찾음) / W=False·RMB=True
  → 마우스만 되고 키보드만 안 됨 → IME 한글 모드가 원인
  activeInputHandler = 2(Both) 확인 → 구 Input 활성, 포커스 문제 아님

## 파라미터 (현재 기본값)
  moveSpeed=10, fastMoveSpeed=25, mouseSensitivity=2
  jumpHeight=2.5, gravity=25

## 조작
  우클릭+드래그 — 시선 회전 / WASD — 이동 / Space — 점프 / Shift — 가속

## 수정 파일
  Scripts/Core/FreeCameraController.cs (전면 재작성)
  Scripts/Managers/GameFlowManager.cs (OnPlayerTeleportRequested CC-safe)

[세션 2] 가이드 모드 디버그 스킵 (F8 / Backspace)
────────────────────────────────────────────────────────────────

## 배경
  디버깅할 때마다 가이드 안내 시나리오(~30초)를 매번 봐야 해서 불편 →
  특정 키로 즉시 자유 모드로 스킵.

## 구현

  Scripts/Managers/GameFlowManager.cs
    - Inspector: _enableGuideSkip(bool), _skipGuideKey(KeyCode, 기본 Backspace)
    - Update()에서 _currentNPC 존재 + 키 입력 시 SkipGuide()
      (IsGuideMode static 대신 _currentNPC로 판단 → 도메인 리로드 영향 없음)
    - SkipGuide() 순서:
        1. _currentNPC.AbortScenario()        (시나리오 코루틴 중단)
        2. _currentNPC.JumpToCreationView()   (창작물 앞 순간이동 — Step 2 동일)
        3. _motionPromptUI.Close()/_signatureConfirmUI.Close()  (열린 UI 닫기)
        4. OnFreeModeSwitched()                (자유모드 전환 팝업)
        5. OnGuideFinished()                   (IsGuideMode=false·Plaza 진입)

  Scripts/Character/GuideNPCController.cs
    - AbortScenario(): StopAllCoroutines + idle
    - JumpToCreationView(): myCreationWaypoint로 TeleportTo (이벤트 구독 중 호출)

  Scripts/UI/MotionPromptUI.cs
    - Close(): 콜백 실행 없이 입력창 닫기

  Scripts/UI/SignatureMotionConfirmUI.cs
    - Close(): 콜백 실행 없이 다이얼로그 닫기

## 주의
  - 노트북 F키는 Fn 가로채기 가능 → 기본 키 Backspace
  - 전시 빌드에선 _enableGuideSkip 해제 권장

[세션 3] 서버 모드 스킵 보강 — 오브제 로드 대기 후 뷰 부착
────────────────────────────────────────────────────────────────

## 문제
  서버 모드는 오브제(GLB)를 비동기 로드. 정상 흐름은 가이드(~25초) 동안
  로드가 끝나지만, 일찍 스킵하면 OnGuideFinished 시점에 오브제가 아직 null
  → AttachViewToCurrentSession이 스킵돼 내 창작물 투표 뷰 누락.

## 구현
  Scripts/Object/GeneratedObjectSpawner.cs
    - _spawnedObject는 GLB 로드 완료 후에만 설정됨(확인) → 폴링으로 감지 가능

  Scripts/Managers/GameFlowManager.cs
    - OnGuideFinished: objectGO==null && Server모드이면
      AttachCurrentCreationWhenObjectLoaded 코루틴 시작
    - 코루틴: GetSpawnedObject()가 채워질 때까지 폴링(최대 30초),
      완료 시 plaza.AttachCurrentObjectLate(obj) 호출

  Scripts/Plaza/PlazaManager.cs
    - _currentViewAttached 플래그(중복 방지)
    - AttachCurrentObjectLate(GameObject): 늦게 도착한 오브제로 뷰 부착
      (이미 부착됐거나 null이면 무시)

## 동작
  서버 모드 일찍 스킵 → 광장 즉시 진입(다른 창작물) +
  내 오브제 로드 완료 순간 내 창작물 뷰 자동 부착.
  Mock/정상 흐름은 코루틴 미시작 → 기존과 동일.

[세션 4] 시그니처 동작 설정 — 나가기 확인 캡션 수정
────────────────────────────────────────────────────────────────

## 요청
  시그니처 설정 UI에서 "나가기" 확인 시, 아니오 밑 문구를
  "다른 동작도 해볼래요!" → "시그니처 동작 설정으로 돌아갈래요"로 변경.

## 구조
  NoButton에 TMP 2개: "아니오"(라벨) + 보조 캡션("다른 동작도 해볼래요!").
  캡션은 프리팹 고정값이라 시그니처 확인/나가기 확인 다이얼로그가 공유.

## 구현
  Scripts/UI/SignatureMotionConfirmUI.cs
    - _noCaptionText 필드 + Show(noCaption) 파라미터 추가
      (null이면 기본 캡션 복원, 값 전달 시 덮어씀 → 다른 다이얼로그 영향 없음)
    - Awake에서 _noCaptionText 미연결 시 NoButton 자식 중
      텍스트가 더 긴 TMP를 캡션으로 자동 탐색 (Inspector 연결 없이 동작)

  Scripts/Plaza/OwnCreationInteractor.cs
    - ShowExitConfirm: noCaption "시그니처 동작 설정으로\n돌아갈래요" 전달

## 결과
  나가기 확인 → "시그니처 동작 설정으로 돌아갈래요"
  시그니처 확인 → "다른 동작도 해볼래요!" (기본 유지)
