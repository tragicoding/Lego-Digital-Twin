[세션 1] 배회 즉시 시작 — "제자리 걷기" 해결
────────────────────────────────────────────────────────────────

## 증상
  자유 모드 진입 후 캐릭터가 스폰·걷기 애니는 바로 하는데, 몇 초간 제자리에서
  걷다가 그제서야 이동.

## 원인
  오브제 NavMeshObstacle 의 carveOnlyStationary=true(정지 0.5초 후 carve) 때문에,
  에이전트가 첫 경로를 잡은 직후 carve 가 들어와 경로가 무효화 → 몇 초 멈춤.
  또한 걷기 애니를 무조건 켜서(경로 대기 중에도) "제자리 걷기"로 보임.

## 수정 (PlazaWanderingCharacter / PlazaManager)
  - NavMeshObstacle.carveOnlyStationary=false → 스폰 즉시 carve(오브제는 낙하 없이 고정).
  - 걷기/정지 애니를 실제 Agent 속도로 동기화(SyncWalkAnim) → 경로 대기 중엔 idle.
  - 경로 무효(PathInvalid) 감지 시 즉시 재탐색.
  - 커밋: 4ae4b69

[세션 2] 캐릭터별 "자기 자리" 분산 배회 + NavMesh 광장 한정 베이크
────────────────────────────────────────────────────────────────

## 분산 배회 (사용자 요청: 센터로 몰림 → 분산)
  - 모든 캐릭터가 공유 wanderCenter 한 점을 쓰면 중앙 집중·NavMesh 가장자리 쏠림 발생.
  - PlazaWanderingCharacter.Setup(centerFromSpawn) 추가 → 각 캐릭터가 'NavMesh 안착한
    자기 스폰 위치'를 중심으로 배회 → 스폰 지점이 흩어져 있어 자연 분산.
  - PickNavPoint 폴백: 중심 기준 실패 시 '현재 위치 주변'에서 재샘플 → 중심/반경이
    어긋나도 완전히 멈추지 않음.
  - PlazaManager: Wander Center 비우면(권장) 자기 자리 분산, 지정하면 공용 중심.

## NavMesh 베이크 (Unity Editor 작업)
  - NavMeshSurface 의 Collect Objects 기본값(All)은 위치와 무관하게 씬 전체를 굽는다.
    → 광장만 굽도록 PlazaGround 레이어 추가 후 Include Layers 한정(또는 Volume).
  - 주의: 캐릭터 스폰/배회 구역 바닥이 모두 NavMesh 위여야 함. wanderCenter/Radius 가
    NavMesh 밖이면 목적지를 못 잡아 멈춤(실측으로 확인·수정).
  - 커밋: b645454 (PlazaGround 레이어·씬·베이크 데이터)

## 건물 간격(참고, 코드 아님)
  벽에 끼면 NavMesh 베이크 Agent Radius 를 키워 재베이크(벽에서 안쪽으로 더 깎임).

[세션 3] 접근 시 시그니처 / idle 분기
────────────────────────────────────────────────────────────────

## 요구
  접근 시: 시그니처 없는 캐릭터는 idle 애니메이션, 시그니처 있는 캐릭터는 idle 없이
  바로 시그니처 동작.

## 수정
  - PlacedCharacterController.HasSignature(_signatureClip != null) 추가.
  - PlazaWanderingCharacter.BeginInteraction 분기:
      있음 → SnapFacePlayer + RebaseAnchorToCurrent + PlaySignatureMotion (idle 없이 즉시)
      없음 → SetWalking(false)=idle 재생 + 부드럽게 응시(FaceSmooth)
  - 배회 재개 시 걷기 애니 재동기화(_walking 리셋).
  - 커밋: 91a1457
  ※ 빈 시그니처는 설계상 idle (mock_plaza.json 앞쪽 세션 다수가 signature_motion="").
    idle 이 정지 포즈로 보이면 NPC_AnimatorController 의 Idle 상태 클립 점검 필요.

## 신규: Scripts/UI/NameTag.cs
  - 대상의 '자식이 아닌' 독립 오브젝트로 따라다님 → 대상 스케일(6·12배) 영향 없음.

  - 대상 파괴 시 스스로 정리. GraphicRaycaster 미부착(표시 전용 → EventSystem NaN 회피).

## 신규: Scripts/UI/NameTagSpawner.cs (싱글톤 팩토리)

## 부착 지점 (Mock·Server 공통 합류점 → 서버 동일)
