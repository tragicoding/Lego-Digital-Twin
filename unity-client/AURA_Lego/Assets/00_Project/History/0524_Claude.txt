[세션 3] VRIntroGuide.cs 전면 재작성
────────────────────────────────────────────────────────────────

## 구현 요구사항
  - XR Origin이 시작 위치에서 5초 대기 후 15초 동안 Target Position까지 이동
  - 대기 시간 / 이동 시간 Inspector에서 조정 가능
  - 인트로 전 과정(대기 + 이동)에서 컨트롤러 이동 차단
  - HMD 시선 추적(head tracking)은 항상 유지

## 기존 코드의 문제점
  - 네임스페이스 없음
  - playerMovementScript 단일 MonoBehaviour만 비활성화 → XRI 3.x 다중 provider 처리 불가
  - this.transform 직접 이동 (xrOrigin 지정 불가)
  - Quaternion.Lerp 사용 (Slerp이 올바름)
  - 선형 보간 (SmoothStep 미적용)
  - 원래 활성화 상태 저장/복원 로직 없음

## 변경 사항 (Assets/00_Project/Scripts/Character/VRIntroGuide.cs)

  네임스페이스 추가 : LegoTwin.Character
  using 추가 : UnityEngine.XR.Interaction.Toolkit.Locomotion

  신규 필드:
    [Header("XR Origin")]
      Transform xrOrigin              — 이동 대상 (비워두면 this.transform)
    [Header("위치 설정")]
      Transform startPoint            — 시작 위치 (선택)
      Transform targetPoint           — 목표 위치 (필수)
    [Header("시간 설정 (초)")]
      float waitDuration = 5f         — 대기 시간
      float moveDuration = 15f        — 이동 시간
    [Header("이동 잠금")]
      LocomotionProvider[] locomotionProviders  — 자동 탐색 또는 수동 지정

  이동 잠금 방식:
    - 인트로 시작 시 LocomotionProvider[] 상태 저장 후 전체 비활성화
    - 인트로 종료 시 원래 상태 복원 (인트로 전 꺼진 provider는 그대로 유지)
    - xrOrigin 하위 GetComponentsInChildren<LocomotionProvider> 자동 탐색

  이동 보간:
    - SmoothStep(0, 1, elapsed/moveDuration) — ease-in/out 적용
    - Vector3.Lerp (위치)
    - Quaternion.Slerp (회전)
    - SetPositionAndRotation으로 한 번에 적용

  HMD 시선 추적 유지 근거:
    - HMD head tracking은 카메라 트래킹 레이어에서 처리
    - LocomotionProvider와 무관하게 항상 작동

## Inspector 연결 방법
  VRIntroGuide 컴포넌트 (XR Origin 또는 별도 GameObject에 추가)
    XR Origin        → XR Origin GameObject 드래그
    Start Point      → 시작 위치 Transform
    Target Point     → 목표 위치 Transform (필수)
    Wait Duration    → 5 (기본값)
    Move Duration    → 15 (기본값)
    Locomotion Providers → 비워두면 자동 탐색
