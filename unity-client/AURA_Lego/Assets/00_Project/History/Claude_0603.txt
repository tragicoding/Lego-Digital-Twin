[세션 2] Root Motion 위치 누적 버그 수정
────────────────────────────────────────────────────────────────

## 문제
  Mixamo 애니메이션 루프 재생 시 Root Motion으로 인해
  캐릭터 위치가 매 루프마다 누적되어 점점 땅 속으로 이동

## 해결 방법
  루프 재시작 시점에 캡처된 위치/회전으로 복원 (Bake Into Pose 대안)

## 수정 파일 1: CharacterAnimationController.cs
  - _onLoopRestart (System.Action) 필드 추가
  - PlayMotionClipLooping(AnimationClip clip, System.Action onLoopRestart = null)
    파라미터 추가 (기존 호출 호환 유지)
  - LoopRoutine() — normalizedTime >= 0.95f 감지 시
    _onLoopRestart?.Invoke() 호출 후 Play("Motion", 0, 0f) 재시작

## 수정 파일 2: PlacedCharacterController.cs
  - BuildResetCallback() 추가
    → 호출 시점의 transform.position/rotation + animator.localPosition/localRotation 캡처
    → 루프 재시작마다 캡처값으로 복원 (루트 · Animator 자식 양쪽 대응)
  - PlayMotionFromPrompt() → PlayMotionClipLooping(clip, BuildResetCallback())
  - PlaySignatureMotion() → PlayMotionClipLooping(clip, BuildResetCallback())

## 장기 권장 방법 (코드 수정 없이 근본 해결)
  Unity Import Settings > Animation 탭 > 각 클립:
    Root Transform Rotation → Bake Into Pose ☑
    Root Transform Position (Y) → Bake Into Pose ☑
    Root Transform Position (XZ) → Bake Into Pose ☑

[세션 4] StarObject PlayLoop 타이밍 버그 수정
────────────────────────────────────────────────────────────────

## 에러
  Coroutine couldn't be started because the game object 'StarObject' is inactive!
  HeartEffect:PlayLoop() → PlazaSessionView:SetTopLiked() → Initialize()

## 원인
  starObject.SetActive(true) 직후 같은 프레임에서
  HeartEffect(StarObject 위) 의 StartCoroutine 호출 →
  Unity 내부적으로 아직 inactive 상태로 인식

## 수정 파일: PlazaSessionView.cs
  SetTopLiked(true) 시:
    기존: heartEffect?.PlayLoop() 직접 호출
    수정: StartCoroutine(PlayLoopNextFrame(heartEffect))
          → yield return null (한 프레임 대기)
          → heartEffect?.PlayLoop() 호출
  PlayLoopNextFrame()은 PlazaSessionView(항상 활성)에서 실행되므로
  StartCoroutine 에러 없이 안전하게 동작

[세션 6] FastSky 밤 시간 태양 디스크 완전 제거
────────────────────────────────────────────────────────────────

## 문제
  밤이 되면 태양 디스크가 지평선에 걸려 보임

## 시도 1: Shader.SetGlobalVector("_SunDir", Vector3.down) (실패)
  FastSky는 ShaderGraph 머티리얼 → 글로벌 변수에 반응 안 함

## 시도 2: UpdateSunRotation에서 밤이면 270° 강제 회전 (실패)
  FastSky는 Light 방향이 아닌 머티리얼 내부 값으로 디스크 위치 계산

## 최종 해결: FastSkyDayNight.cs 전면 수정
  - Start(): RenderSettings.skybox 머티리얼 런타임 인스턴스 생성
    (원본 에셋 보호 + 런타임 수정 가능)
    _originalSunIntensity 캐시
  - UpdateURPLighting():
    낮/밤 판정(dotProduct > 0)으로 isDay 결정
    _skyMat.SetVector("_SunDir", sunDir)        ← 머티리얼 직접 설정
    _skyMat.SetFloat("_SunIntensity", 밤이면 0) ← 디스크 강도 0 (이중 보호)
  - UpdateSunRotation(): 밤이면 270° 강제 회전 유지

## 관련 에셋 (참고)
  External Assets/FastSky/ — ShaderGraph 기반 절차적 스카이
  머티리얼: RealisticSky.mat (_SunIntensity 100), StylisedSky.mat (150)
  FastSky_Sun_Color.cs — Light intensity/color 별도 제어 (수정 안 함)
