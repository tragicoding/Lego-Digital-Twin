## PlazaManager.cs 수정

### 추가된 필드
  - _currentSession, _currentCharacterGO, _currentObjectGO
    (현재 관람객 창작물 GO 참조)
  - _likeCounts Dictionary<string, int>
    (세션별 좋아요 수 추적 — Mock 투표 재계산용)

### 추가된 메서드
  RegisterCurrentSession(SessionData, GameObject charGo, GameObject objGo)
    → GameFlowManager가 OnGuideFinished 직전에 호출
    → 이미 씬에 스폰된 현재 관람객 창작물 GO 전달

  AttachViewToCurrentSession()
    → 현재 관람객 오브제 위에 PlazaSessionView Instantiate
    → SessionData → PlazaSessionData 변환 후 Initialize()

  HandleMockLike(string sessionId, int newLikes)
    → _likeCounts 갱신
    → LINQ OrderByDescending으로 1위 세션 재계산
    → 전체 뷰 SetTopLiked() 업데이트

### LoadAndSpawnPlaza() 변경
  - 세션 배치 시 _likeCounts 딕셔너리에 좋아요 수 등록
  - AttachViewToCurrentSession() 호출 추가
  - Debug.Log 강화 (세션 수, spawnPoints 수, 배치 진행상황)
  - mockCharacterPrefab/mockObjectPrefab 미연결 시 명확한 경고

### SpawnSessionAssets() 변경
  - 캐릭터: Vector3.left * 3f (기존 0.5f → 간격 확대)
  - 오브제: Vector3.right * 3f (기존 0.5f → 간격 확대)
  - spawnScale = 12f 적용 (기존 미적용)

[전체 흐름 — 자유 모드 투표]
────────────────────────────────────────────────────────────────

  가이드 종료
    → GameFlowManager.OnGuideFinished()
      → PlazaManager.RegisterCurrentSession(session, charGO, objGO)
      → PlazaManager.EnterPlaza()
          → LoadAndSpawnPlaza()
              → AttachViewToCurrentSession()  (내 창작물)
              → SpawnSessionAssets() × N      (이전 관람객들)
              → PlazaSessionView.Initialize() × N
                  → LikeSystem.Initialize()

  플레이어 근접
    → LikeSystem.OnTriggerEnter("Player")
      → likeButtonUI.SetActive(true)

  버튼 클릭
    → LikeSystem.OnLikePressed()
      → SendLike()
          [Mock] _likes++ → UpdateLikes() → HandleMockLike() → 별 재계산
          [Server] ApiClient.LikeSession() → POST /like → LikeResponse

  WebSocket (Server 모드)
    → PlazaManager.HandleLikesUpdated(WsLikesEvent)
      → 전체 뷰 UpdateLikes() + SetTopLiked() 재계산
