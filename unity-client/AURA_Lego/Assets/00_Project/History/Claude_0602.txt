[세션 1] DialogueUI → NPC 머리 위 World Space 말풍선으로 교체
────────────────────────────────────────────────────────────────

## 변경 목적
  가이드 NPC 대사를 화면 고정 UI 대신 NPC 머리 위에 붙는 World UI로 교체

## 수정 파일: Scripts/UI/DialogueUI.cs

  추가된 필드:
    _followTarget   (Transform)  — 추적할 NPC Transform (런타임 주입)
    _heightOffset   (float, 기본 2.2f) — NPC 기준 위쪽 오프셋
    _rightOffset    (float, 기본 0f)   — NPC 기준 오른쪽 오프셋
    _billboardMode  기본값 false → true 변경

  LateUpdate() 변경:
    _followTarget 있으면 매 프레임 위치 추적
      transform.position = _followTarget.position
                         + Vector3.up * _heightOffset
                         + _followTarget.right * _rightOffset

    Billboard: transform.forward = _mainCamera.transform.forward

  추가된 메서드:
    SetFollowTarget(Transform) — NPC 스폰 후 GameFlowManager가 주입

## 수정 파일: Scripts/Managers/GameFlowManager.cs

  OnSessionLoaded() 내 NPC 스폰 직후:
    _dialogueUI?.SetFollowTarget(npc.transform)

## Unity Inspector 작업 (World Space 전환)

  DialogueUI Canvas:
    Render Mode → World Space
    Event Camera → Main Camera
    Scale → (0.01, 0.01, 0.01)
    DialogueUI: Billboard Mode ☑, Height Offset 12~15, Right Offset 1~3

  FreeModePopupUI / MotionPromptUI:
    Render Mode → Screen Space - Overlay (기존 유지)

## 기능 개요
  - 가이드 모드: 모션 확인 후 "시그니처 동작으로 설정하시겠습니까?" 예/아니오

  - 자유 모드: 이전 관람객 캐릭터에 시그니처 동작 설정
                플레이어 접근 시 자동 루프 재생, 이탈 시 idle 복귀
