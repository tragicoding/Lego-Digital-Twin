## TriLib 설치 방법 (수동, Unity Editor에서)
  1. Unity Editor 실행 → Window > Package Manager
  2. My Assets → TriLib 2 - Model Loading Package → Download → Import
  3. Project Settings > TriLib > "Disable in editor glTF2 importing" 체크
     (glTFast와 .glb 임포터 충돌 방지 — 필수)
  4. TRILIB define 자동 등록 확인
     (TriLibDefineSetup.cs가 자동으로 Scripting Define Symbols에 TRILIB 추가)

## VR 제거 시 성능 이점

  | 항목 | 설명 |
  |------|------|
  | 2배 렌더링 제거 | 왼쪽·오른쪽 눈 각각 렌더 → 단일 렌더로 절반 |
  | 해상도 복귀     | Quest 기준 1832×1920×2 → 1920×1080 |
  | fps 타겟 완화   | 90fps 강제 → 60fps 충분 |
  | XR 오버헤드 제거 | 컴포지터, XR SDK 컴포넌트 제거 |

## FreeCameraController 현재 상태
  이미 키보드+마우스 완전 동작. XR 컴포넌트 자동 비활성화 포함.
  코드 수정 없이 Project Settings 변경만으로 전환 가능.

## Unity Editor 전환 절차 (코드 변경 없음)

  Step 1 — XR 비활성화 (성능 핵심)
    Edit > Project Settings > XR Plug-in Management
    → PC 탭 > OpenXR 체크 해제

  Step 2 — EventSystem 교체
    Hierarchy > EventSystem 선택
    → XR UI Input Module 제거 → Standalone Input Module 추가
    (마우스 클릭이 UI에 안 먹히는 문제 방지)

  Step 3 — FreeCameraController 활성 확인
    Hierarchy > XR Origin > Camera Offset > Main Camera
    → FreeCameraController 컴포넌트가 enabled 상태인지 확인

  Step 4 — Mock 모드 확인
    Hierarchy > SessionManager > Data Source Mode = Mock 확인

## 조작법 (전환 후)
  마우스 오른쪽 버튼 + 드래그  — 시선 회전
  WASD                          — 이동
  Space                         — 점프
  Shift                         — 빠른 이동
  Backspace                     — 가이드 스킵 (자유모드 바로 진입)

[세션 5] 광장 오브제 배치 버그 수정 (버그 3종)
────────────────────────────────────────────────────────────────

## Bug 1 — 오브제 XZ 위치 밀림 (해결)

  원인: RuntimePhysicsUtil.SetupSimplePhysics() 에서 FreezeRotation만 설정,
        XZ 이동이 열려 있어 중력 낙하 중 바닥 콜라이더 형태로 인해 밀림.
  수정: RigidbodyConstraints에 FreezePositionX | FreezePositionZ 추가.
        오브제가 스폰 X/Z 위치를 유지하며 수직 낙하.

## Bug 2 — 오브제 땅 파묻힘 (Mock 프리팹, 해결)

  원인:
    ① CollisionDetectionMode.Discrete — 고속 낙하 시 바닥 콜라이더 관통(tunneling).
    ② SetupSimplePhysics()에서 기존 Collider 있으면 return — 프리팹의
       잘못된 BoxCollider가 그대로 사용(center/size가 scale·pivot 불일치).
  수정:
    ① CollisionDetectionMode.Continuous 추가.
    ② 기존 Collider 유무 무관하게 항상 Renderer.bounds로 루트 BoxCollider 재계산
       (AddBoundsBoxCollider → ApplyBoundsBoxCollider 로 변경).

## Bug 3 — GLB 오브제 땅 파묻힘 (서버 모드, 해결)

  원인: SpawnObjectFromServerAsync() 에서 GLTFast InstantiateMainSceneAsync()
        완료 직후 SetupObjectPhysics() 호출 → 이 시점 renderer.bounds 미초기화
        → BoxCollider.size ≈ (0,0,0) → 충돌 없이 낙하 관통.
  수정:
    ① PlazaManager: await InstantiateMainSceneAsync() 후 await Awaitable.NextFrameAsync()
       1프레임 대기 → renderer.bounds 초기화 보장.
    ② RuntimePhysicsUtil: bounds.y < 0.001f 이면 기본값 (center=0, size=1)
       안전망 추가 → 경고 로그 출력.

## Bug 4 — EventSystem NaN 경고 (해결)

  원인: XR Input Module → Standalone Input Module 전환 후 EventSystem이
        모든 WorldSpace Canvas에 마우스 레이를 쏘기 시작.
        PlazaSessionView는 point.rotation으로 고정 배치 → 카메라와 edge-on이 되는
        순간 GraphicRaycaster 교점 계산이 NaN.
  수정: PlazaSessionView.LateUpdate() 추가 — NPCSpeechBubble과 동일하게
        transform.forward = _cam.transform.forward (빌보드 회전).
