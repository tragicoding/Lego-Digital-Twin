[세션 6] VR 가상 키보드 레이아웃 수정 (VrKeyboard.cs)
────────────────────────────────────────────────────────────────

## 증상
  ① 키 버튼이 키보드 폭 밖으로 넘침. ② 버튼이 위로 몰리고 아래는 빈 공간.

## 원인
  Rebuild() 가 키를 폭/높이에 맞추는 로직 없이 HorizontalLayoutGroup 에 나열만 함.
  라벨 TMP 가 키보다 넓어(160px) 삐져나옴. VerticalLayoutGroup UpperCenter +
  고정 행높이 → 위 몰림·아래 공백.

## 수정
  - 키 너비 = (행 컨테이너 안쪽 폭 − 간격합) ÷ 최대 열수 로 역산, 각 키 LayoutElement 로 강제.
    짧은 행 MiddleCenter 가운데 정렬, 공백/완료는 여러 셀 폭으로 넓게.
  - 행 높이 = (안쪽 높이 − 간격) ÷ 행수 로 역산(_fillHeight) → 세로도 꽉 채움.
  - 라벨을 키에 꽉 채우고(anchor 0~1) enableAutoSizing → 긴 라벨도 안 넘침.
  - EnsureRowsLayout(): rowsParent 에 VerticalLayoutGroup 보장 + 안쪽 여백(_padLeft/Right/Top/Bottom).
  - 인스펙터 노출: _rowSpacing·_keyMinWidth·_fallbackWidth/Height·_rowMinHeight·_fillHeight·여백 4개.

## 트러블슈팅
  UnityException: "set_left ... not allowed from MonoBehaviour constructor/field initializer"
  원인: `[SerializeField] RectOffset _padding = new RectOffset(...)` 필드 초기화 금지.
  해결: int 4개(_padLeft/Right/Top/Bottom)로 분리, RectOffset 은 EnsureRowsLayout() 런타임 생성.

## 커밋 (선택 스테이징)
  VrKeyboard.cs 전체 + Main.unity 의 VrKeyboard 필드 hunk만 스테이징.
  무관 드리프트(dataSourceMode:0 테스트 토글·mockCharacterPrefab guid·Image 색/스프라이트·폰트)
  는 제외(§2 git status 확인 규칙·관례).

[세션 7] VR 대기 단계 흰 화면 — WaitingWorldBlanker (신규)
────────────────────────────────────────────────────────────────

## 요구
  VR에서 START(가이드 시작) 전 대기영상·이름입력 단계 동안 주변 월드를 가리고
  흰 공간만 보이게 해 영상에 집중.

## 방식 결정: 카메라 컬링
  대기 중 Main Camera → clearFlags=SolidColor(흰색) + cullingMask=지정 레이어(UI)만.
  월드 지오메트리(Default/Ground/Props/…) 전부 컬링 → 확실히 흰색. START 시 원복.

## 신규: Scripts/Core/WaitingWorldBlanker.cs
  - 게이트: GameFlowManager.GuideStarted(=START) 전 && XRModeManager.Mode==VR 이면 블랭크,
    GuideStarted true 되면 캡처해 둔 clearFlags/color/cullingMask 로 복구. (FastSkyDayNight 와 동일 패턴)
  - 정적 플래그 1회 읽기 저결합(EventSystemModeBinder/ModeAdaptiveCanvas 와 동급). 데스크톱·Mock/Server 무영향.
  - 씬 리로드(전시 루프) 시 GuideStarted=false → 자동 재적용.
  - 인스펙터: _visibleLayers(기본 UI)·_blankColor(흰)·_onlyInVR·_camera(비우면 Camera.main).

## 주의 (컨트롤러 조작)
  UI만 렌더하면 컨트롤러 레이/리티클이 안 보일 수 있음(레이는 Default 레이어).
  → Default 에는 월드도 있어 마스크에 추가 불가 → 레이 LineVisual 을 UI 레이어로 옮겨야 함(세션 8).

## 커밋
  WaitingWorldBlanker.cs + .meta 만 커밋(스크립트 = 구현 산출물).
  씬 배치(컴포넌트 부착)·XR 리그 레이어 변경은 무관 드리프트와 섞여 미커밋(추후 정리).

[세션 9] VR 지도 토글 = 오른손 B 버튼 + VR 시 MapButton 숨김 (MapTeleportUI.cs)
────────────────────────────────────────────────────────────────

## 요구
  VR에서 화면 지도 버튼 대신 컨트롤러 B 버튼으로 지도 패널 열기/닫기 토글. 버튼은 숨김.

## 구현
  - Update(): VR 모드 한정, 오른손 secondaryButton(=B) edge 감지 → 기존 ToggleMap() 호출.
    InputDevices + CommonUsages.secondaryButton 폴링(인스펙터 배선 0, XRModeManager 착용감지와 동일 방식).
  - OnEnable(): _bPressedLast 동기화(활성 순간 오작동 방지) + ApplyMapButtonVisibility().
  - ApplyMapButtonVisibility(): VR && _vrBButtonToggle 이면 MapButton 숨김(B 전용),
    데스크톱은 표시(마우스 클릭 유지). B 토글 OFF면 VR에서도 버튼 남김(조작 수단 보존).
  - 자유 모드에서만 컴포넌트 활성 → 가이드/대기 단계엔 B가 지도에 영향 없음.

## 커밋
  MapTeleportUI.cs 단일 파일.
