  - 필드: public Transform playerTeleportPoint
  - 메서드: TeleportTo(Vector3) — NPC 즉시 이동 + 플레이어 이벤트 발행

## 최종 GuideScenarioRoutine() 단계

  Step 0: 등장 — guideArrivalPoint까지 걸어서 이동 + FacePlayerRoutine()
  Step 1: 입장 인사
          Say("MINIVERSE에 오신 걸 환영해요!")                          → 3초
          Say("저는 당신이 만든 '{_npcName}'이에요.")                    → 3초
          Say("광장에 가서 오브제들을 확인해볼까요?")                     → 3초
  Step 2: 순간이동
          TeleportTo(myCreationWaypoint.position)
          OnPlayerTeleportRequested 이벤트 발행 → 플레이어도 이동
          FacePlayerRoutine()
          Say("짜잔! 당신이 만든 오브제에요")                            → 3초
  Step 3: 모션 프롬프트 입력
          Say("캐릭터에는 원하는 동작을 입력할 수 있어요, 한번 해볼까요?") → 3초
          OnMotionPromptRequested 이벤트 발행 → 입력 대기
          placedCharacter.PlayMotionFromPrompt(motionInput)           → 2초
  Step 4: 투표 설명
          Say("광장에서는 다른 창작자들이 만든 오브제들도 볼 수 있어요.") → 3초
          Say("다가가서 마음에 드는 오브제에게 투표를 해보세요!")          → 3초
  Step 5: 자유 모드 전환
          OnFreeModeSwitched 이벤트 발행 → 팝업 표시
          1.5초 대기
          OnGuideFinished 이벤트 발행 → 자유 모드 전환

[세션 6] 플레이어 동반 순간이동 구현
────────────────────────────────────────────────────────────────

## 배경
  TeleportTo() 호출 시 NPC만 순간이동하고 플레이어는 제자리에 남는 문제

## 구현 흐름

  GuideNPCController.TeleportTo(npcPosition)
    → transform.position = npcPosition          (NPC 이동)
    → OnPlayerTeleportRequested?.Invoke(dest)   (이벤트 발행)
        dest = playerTeleportPoint.position
               (없으면 npcPosition)

  GameFlowManager.OnPlayerTeleportRequested(destination)
    → _playerFollowGuide.transform.position = destination
      (_playerFollowGuide가 XR Origin 루트에 붙어있으므로 바로 이동)

## 관련 파일
  GuideNPCController.cs  — TeleportTo(), OnPlayerTeleportRequested 이벤트
  GameFlowManager.cs     — OnPlayerTeleportRequested 핸들러
  GeneratedCharacterSpawner.cs — playerTeleportPoint Inspector 필드 + NPC 주입

  GuideNPCController에 isKinematic 전환 코드 추가

## 발생한 문제
  1. 배치 캐릭터: 공중에 부유 (CapsuleCollider center 오계산)
  2. 가이드 캐릭터: 몸이 땅에 박힘 (FacePlayerRoutine과 Rigidbody 충돌)

## 결론
  Rigidbody + transform 직접 조작 방식이 근본적으로 충돌
  → 캐릭터 중력 설정 코드 전체 취소 (기본 스폰 방식 유지)
  → 스폰 포인트를 바닥 높이에 직접 맞추는 방식으로 운용

## 최종 상태 (취소 후)
  GeneratedCharacterSpawner: 중력 관련 필드/메서드 없음
  GuideNPCController: _rigidbody 필드/Awake/isKinematic 전환 코드 없음

[세션 15] 모션 루프 재생 구현
────────────────────────────────────────────────────────────────

## 문제
  프롬프트 입력 시 애니메이션이 한 번만 재생되고 다시 Idle로 복귀
  (Animator의 Motion → Idle 전환이 Exit Time=1.0 이기 때문)

## 구현 (CharacterAnimationController.cs)
  - 필드 추가: _loopCoroutine
  - PlayMotionClipLooping(AnimationClip):
      _overrideController[MOTION_SLOT] = clip
      SetTrigger("motion")  ← 초기 진입 (세션 17 참고: Play() 대신 SetTrigger 사용)
      StartCoroutine(LoopRoutine())
  - StopMotionLoop(): 루프 코루틴 중지 + animation_idle()
  - LoopRoutine() 코루틴:
      WaitUntil(IsName("Motion"))  ← Motion 상태 진입 대기
      Loop: normalizedTime >= 0.95f 감지 → Animator.Play("Motion", 0, 0f) 처음부터 재시작
      → Idle로 빠져나가지 않고 끊김 없이 무한 반복

## PlacedCharacterController.cs 변경
  PlayMotionFromPrompt() → 기존 PlayMotionClip() 대신 PlayMotionClipLooping() 호출

## 수정 파일
  Scripts/Character/CharacterAnimationController.cs
  Scripts/Character/PlacedCharacterController.cs

[세션 16] 프롬프트 입력 전 배치 캐릭터 애니메이션 정지
────────────────────────────────────────────────────────────────

## 요구사항
  프롬프트를 입력하기 전까지 광장 배치 캐릭터가 Idle 애니메이션을
  재생하지 않도록 정지

## 구현 (PlacedCharacterController.cs) — 최종 형태
  Awake(): _animator = GetComponentInChildren<Animator>();
           _animator.speed = 0f;   ← 애니메이션 정지 (포즈 유지)
  PlayMotionFromPrompt(): 첫 입력 시 _animator.speed = 1f 로 재개

  처음엔 _animator.enabled=false 로 시도했으나, 재활성(true) 시
  Animator가 재초기화되며 90도 회전이 발생 (세션 17 참고).
  → enabled 대신 speed 토글로 변경하여 해결.

[세션 17] 프롬프트 입력 시 캐릭터 90도 회전 문제 해결
────────────────────────────────────────────────────────────────

## 문제
  프롬프트 입력 → 애니메이션 재생과 동시에 배치 캐릭터가 90도 회전
  (정면을 보던 캐릭터가 오른쪽/왼쪽으로 돌아감)

## 시도 1: applyRootMotion = false (실패)
  PlayMotionClipLooping()에서 _animator.applyRootMotion = false 설정
  → 회전이 Root Motion 경로가 아니라서 효과 없음 → 취소

## 시도 2: LateUpdate 회전 잠금 (실패)
  PlacedCharacterController.LateUpdate()에서 transform.rotation 및
  _animator.transform.localRotation 을 저장값으로 강제 복원
  → 여전히 시각적 회전 발생 → 취소

## 시도 3: Play() → SetTrigger() 교체 (부분 성공)
  PlayMotionClipLooping() 초기 진입을 Animator.Play("Motion",0,0f) →
  SetTrigger("motion") 으로 변경
  → 초기 진입 회전은 사라짐 (현재 코드에 반영, 세션 15)

## 최종 원인 분석
  _animator.enabled = false → true 재활성 시 Animator가 재초기화되며
  Idle 포즈(frame 0)가 강제 적용되어 90도 회전 발생

## 최종 해결
  세션 16의 speed=0 / speed=1 방식으로 전환 (enabled 토글 폐기)
  → Animator 상태가 유지되어 재초기화 없음 → 회전 없음

## 수정 파일
  Scripts/Character/CharacterAnimationController.cs (SetTrigger 유지, LateUpdate 잠금 제거)
  Scripts/Character/PlacedCharacterController.cs (speed 토글)
