1. Docker exec로 psql 직접 접속 (가장 빠름)


docker exec -it lego_db psql -U lego -d lego_twin
접속 후 주요 명령어:


\dt                          -- 테이블 목록
SELECT * FROM sessions;      -- 세션 전체 조회
SELECT * FROM assets;        -- 에셋 전체 조회
SELECT id, nickname, status FROM sessions ORDER BY created_at DESC;
\q                           -- 종료
