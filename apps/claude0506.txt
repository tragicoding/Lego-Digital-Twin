전체 실행 파이프라인

1. 백엔드 서버 시작 (Linux/WSL2)


cd /home/jskim/capstone/Lego-Digital-Twin
conda run -n triposr uvicorn apps.backend.tripo.main:app --host 0.0.0.0 --port 8000 --reload
확인: http://localhost:8000/health → {"status":"ok"}
Swagger: http://localhost:8000/docs

2. Windows 카메라 클라이언트 실행


# D:\python_camera\ 에서
pip install -r requirements.txt   # 최초 1회

python capture.py          # Space 키마다 촬영
python capture.py --auto   # 5초마다 자동 촬영
3. 데이터 흐름 (자동)


[Windows 카메라]
  촬영 → image_00.png, image_01.png ...
        ↓ POST /hardware/camera/capture
[백엔드]
  storage/captures/ 에 저장
        ↓ Tripo3D API v3.0 (비동기, ~2분)
  storage/models/image_00_20260505.glb 생성
        ↓ 복사
  unity-client/.../External Assets/capstone1/3d_model/
        ↓ WebSocket 브로드캐스트
  { "type": "model_ready", "filename": "image_00_...glb" }

[Unity]
  /ws/unity 구독 → model_ready 수신 → GLB 로드
4. Arduino 하드웨어 (별도)


# Arduino → 백엔드로 POST
POST /hardware/event  {"type": "light", "value": 300}   # 조명
POST /hardware/event  {"type": "clap",  "value": 1.0}   # 박수
# → 백엔드가 Unity WebSocket으로 즉시 전달
5. Unity WebSocket 연결

Unity 측에서 ws://localhost:8000/ws/unity 에 연결하면 아래 메시지를 수신합니다:

메시지 type	트리거
connected	연결 직후
model_ready	GLB 생성 완료
model_failed	변환 실패
atmosphere	조명 이벤트
fireworks	박수 이벤트
상태 확인용 엔드포인트:


GET /tripo/status/{task_id}   # 변환 진행 상태
GET /unity/models             # 생성된 GLB 목록
GET /unity/health             # Unity 연결 수
