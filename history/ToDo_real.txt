[3] : 전시회 자동화 Script
1. 현재는 앱 마지막 화면(loading의 마지막 화면)의 "완료되었습니다!" 인데, 화면 맨 밑에 <새롭게 시작하기> 버튼 추가 했음.
현재 큐가 어떻게 구현되고 있는지 모르겠는데, 전시회에서는 다음 상황이 발생할 수 있음. 
- 유니티를 플레이 하고 있는 사용자a
- 방금 레고를 다 조립하고 모델다운까지 끝낸 사용자 b
- 현재 앱으로 레고 이미지 촬영중인 사용자 c
이러한 상황에서, 나는 unity_queue라는 큐에 [b,c]가 있고,(a는 자기 차례이므로 현재 실행중)
unity에서 <종료하기>버튼 UI가 있는데, 그거 누르면 현재 session이 버려짐.(물론, DB에는 저장되어야함.bubble_Text나, 시그니처 동작,모델,좋아요 등)
그 다음 다시 unity가 실행되면, 현재 큐의 b가 가장 앞에 있으니까, b session을 기준으로 unity가 실행되어야 함.
또한, 앱의 마지막 화면에서 <새롭게 시작하기> 버튼 누르면 방금 완료된 session은 unity_queue에 들어감.
언제나 unity를 실행할 때 해당 session은 unity_queue의 가장 앞 세션.

2. 현재는 서버,앱,워커,레디스 실행할때마다 전부 수동으로 실행했음. 근데 이 또한 자동화 해야한다.
-> 하나의 명령어 만으로 이것들이 모두 실행되어야 함.

기능
1. 서버
-IP번호 상태 확인(WSL,Windows)
-네트워크 연결 상태(port별로.)

2. worker

    (4)session 생성 시작시각을 알수 있도록
    (5)캐릭터fbx,glb, 오브제glb가 제대로 다운 됬는지 true or false

4. 데이터 관리

- 세션 삭제
