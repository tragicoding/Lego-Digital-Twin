- Loading page button "이동하기" moves the session from session_queue to unity_queue and returns to start.
- Unity calls GET /sessions/active to pop the first unity_queue item into runtime.
- DB Session is created only when Unity runtime starts.
- Unity completion calls POST /sessions/unity-queue/advance, moving active runtime session to history_queue.
- Admin rejecting a history_queue item sets DB sessions.is_true = false.
- Unity plaza endpoint filters out is_true=false sessions.
