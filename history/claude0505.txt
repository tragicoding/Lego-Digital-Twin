### 통신 구조 요약

engine-vision → POST /voxels/upload → backend:8000 → WS /ws/unity → Unity
hardware      → POST /hardware/event → backend:8000 → WS /ws/unity → Unity

백엔드 실행: conda run -n charuco uvicorn apps.backend.main:app --host 0.0.0.0 --port 8000
파이프라인:  conda run -n charuco python -m apps.engine-vision.charuco.pipeline --images_dir ... --upload
