1. 프로젝트 개요
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

사용자가 물리 세계에서 레고를 조립하면, 카메라가 이를 촬영하고
Tripo3D API를 통해 3D 모델로 변환하여 Unity VR 레고 놀이공원
안에 실시간으로 재현하는 디지털 트윈 시스템.

주요 인터랙션:
  - 레고 모형 조립  → Unity 공원 내 동일 3D 모형 자동 생성
  - 조명 밝기 조절  → VR 대기 변화 (낮/노을/밤/흐림/자정)
  - VR 착용 중 박수 → 불꽃 축제 이벤트 트리거

개발 환경:
  - OS     : Windows 11 + WSL2 (Ubuntu 24.04)
  - GPU    : NVIDIA RTX 4070 Laptop
  - Python : 3.11 (Conda env: triposr)
  - Unity  : 6000.x (Windows 실행)
  - CUDA   : 11.8

4. 백엔드 API 엔드포인트 전체 목록
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[Hardware 라우터] /hardware
  POST /hardware/camera/capture
    - 요청: multipart/form-data (이미지 파일)
    - 동작: 이미지 저장 → 백그라운드에서 Tripo 파이프라인 시작
    - 응답: { task_id, status: "queued", filename }

  POST /hardware/event
    - 요청: { type: "clap"|"light", value: float }
    - 동작: Unity WebSocket으로 즉시 브로드캐스트
    - clap  → { type: "fireworks", intensity }
    - light → { type: "atmosphere", atmosphere, lux }
    - 응답: { status, unity_clients, message }

  GET /hardware/status
    - 응답: 현재 조명 상태 { lux, atmosphere }

[Tripo 라우터] /tripo
  GET /tripo/status/{task_id}
    - 응답: { task_id, status, filename, download_url, error }
    - status: queued | processing | success | failed

  POST /tripo/upload
    - 수동 이미지 업로드 (테스트/디버깅용)
    - 동작: /hardware/camera/capture 와 동일한 파이프라인

[Unity 라우터] /unity
  GET /unity/models
    - 응답: 생성된 GLB 파일 목록 (최신순)
    - [{ filename, download_url, unity_path, size_bytes }]

  GET /unity/models/{filename}
    - GLB 파일 직접 다운로드 (Unity가 HTTP로 요청)
    - Content-Type: model/gltf-binary

  GET /unity/health
    - 응답: { unity_clients: N }  (연결된 WebSocket 수)

[WebSocket]
  WS /ws/unity
    - Unity 클라이언트가 연결 유지
    - 서버 → Unity 메시지 타입:
        connected  : 연결 확인
        model_ready: { filename, download_url }
        model_failed: { task_id, error }
        atmosphere : { atmosphere, lux }
        fireworks  : { intensity }

[헬스체크]
  GET /health
    - 응답: { status: "ok", unity_clients: N }

5. 3D 모델 생성 파이프라인 상세
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1. 카메라 촬영 (Windows, D:\python_camera\capture.py)
  - USB 카메라 인덱스 1번 고정 (cv2.CAP_DSHOW)
  - Space 키 → 한 장 촬영
  - 파일명: image_00.png, image_01.png ... (순번 자동 증가)
  - 로컬 저장: D:\python_camera\captures\
  - 즉시 POST → http://localhost:8000/hardware/camera/capture

Step 2. 이미지 수신 및 태스크 등록 (백엔드)
  - 이미지를 storage/captures/ 에 저장
  - 인메모리 task_store에 { status: "queued" } 등록
  - FastAPI BackgroundTasks로 비동기 파이프라인 시작
  - 즉시 { task_id, status: "queued" } 반환

Step 3. Tripo3D API 호출 (tripo_service.py)
  3-1. 이미지 업로드 → STS 토큰 획득
       POST https://api.tripo3d.ai/v2/openapi/upload/sts
       응답: image_token

  3-2. image_to_model 태스크 생성
       POST https://api.tripo3d.ai/v2/openapi/task
       Body: { type: "image_to_model", file: { type: "png", file_token } }
       응답: task_id (Tripo 내부 ID)

  3-3. 완료 폴링 (3초 간격, 최대 300초)
       GET https://api.tripo3d.ai/v2/openapi/task/{task_id}
       status: queued → processing → success

  3-4. GLB 다운로드
       result["output"]["pbr_model"] URL에서 GLB 바이너리 다운로드
       저장: storage/models/{stem}_{timestamp}.glb

Step 4. Unity 알림 (ws/unity_ws.py)
  - WebSocket 브로드캐스트:
    { type: "model_ready", filename: "...", download_url: "/unity/models/..." }
  - 연결된 모든 Unity 클라이언트에 전송

Step 5. Unity GLB 수신 및 씬 배치 (Windows Unity)
  5-1. BackendClient.cs: WebSocket 메시지 수신
       OnModelReady 이벤트 발행 (filename 전달)

  5-2. ModelLoader.cs: HTTP 다운로드
       UnityWebRequest → GET http://localhost:8000/unity/models/{filename}
       저장: Application.persistentDataPath/models/{filename}

  5-3. GLTFast (com.unity.cloud.gltfast 6.18.0)로 GLB 로드
       GltfImport.LoadFile() → InstantiateMainSceneAsync()
       씬에 "LegoModel" GameObject로 배치

6. 네트워크 통신 구조
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

같은 컴퓨터(Windows + WSL2) 환경:
  - WSL2는 Windows의 localhost:8000으로 자동 포트 포워딩
  - Unity(Windows) → http://localhost:8000 으로 직접 접근 가능
  - 별도 포트포워딩/방화벽 설정 불필요 (Windows 11 + WSL2 기본)

프로토콜 용도:
  - HTTP   : 이미지 업로드, GLB 다운로드, 상태 조회 (단방향 요청)
  - WebSocket: 실시간 이벤트 알림 (백엔드→Unity 푸시)

7. Unity C# 스크립트 역할 분담
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BackendClient.cs (Singleton, DontDestroyOnLoad)
  - ws://localhost:8000/ws/unity 연결 및 자동 재연결 (3초)
  - 메시지 파싱 후 이벤트 발행:
      OnModelReady(string filename)
      OnAtmosphere(string atmosphere, float lux)
      OnFireworks(float intensity)
  - async 수신 루프 → UnityMainThread.Enqueue()로 메인 스레드 전달

UnityMainThread.cs
  - 백그라운드 스레드 작업을 Update()에서 처리하는 큐
  - WebSocket 수신(별도 스레드) → Unity API 호출(메인 스레드) 브릿지

ModelLoader.cs
  - BackendClient.OnModelReady 구독
  - UnityWebRequest로 GLB HTTP 다운로드
  - Application.persistentDataPath/models/ 에 캐싱
  - GltfImport로 씬에 배치 (이전 모델 자동 제거)
  - Inspector 설정: Spawn Position, Rotation, Scale
